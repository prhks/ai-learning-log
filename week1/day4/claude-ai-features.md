# Claude.ai Features

## Artifacts
- Artifacts help Claude generate and maintain long structured outputs.
- Interactive and can be previewed or edited in real-time.
- Useful for working with:
  - Code files
  - Documentation
  - Prompt templates
  - HTML/SVG content
  - Mermaid diagrams
  - React components
- Makes iterative improvement easier within a single task.

## Projects
- Organize related conversations with shared context.
- Add custom instructions specific to each project.
- Upload project knowledge (documents, code files) for reference.
- Maintains consistency across multiple conversations.

## Code Understanding
- Claude can analyze code logic and structure.
- Identifies bugs, edge cases, and refactoring opportunities.
- Supports multiple programming languages.
- Can generate code, explanations, and documentation.
- Works across multiple files and understands project structure.
- Suggests tests and improvements.
- Cannot execute code but performs strong static reasoning.

## Vision Capabilities
- Claude can analyze images such as:
  - UI screenshots
  - Diagrams
  - Error screenshots
  - Handwritten notes
- Can handle multiple images in one conversation.
- Performs OCR (reads text from images).
- Useful for UI reviews, accessibility checks, and documentation.
- Limitation: Cannot identify specific individuals in photos.

## Document Analysis
- Can read and analyze PDF documents directly.
- Extracts and works with structured data.
- Supports long-form document summarization and Q&A.

## Extended Context
- Handles very long conversations (hundreds of thousands of tokens).
- Maintains context across extended discussions.
- Useful for complex, multi-step tasks and deep dives.

## Data Analysis
- Works with structured data (CSV, JSON, etc.).
- Can analyze datasets and identify patterns.
- Helps create data visualizations and reports.

## Multi-language Support
- Works with many programming languages.
- Supports natural language in multiple languages.
- Can translate and localize content.
