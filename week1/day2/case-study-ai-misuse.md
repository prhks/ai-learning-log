# Case Study: AI Misuse in Software Development

## Scenario
A developer uses AI to generate database access code and deploys it without review.

## What Went Wrong
- SQL injection vulnerability introduced
- No security review performed
- Overreliance on AI output

## Risks Created
- Data breach
- Loss of user trust
- Legal consequences

## How It Should Have Been Handled
- Human code review
- Security testing
- Limited AI use for suggestions only

## Lesson Learned
AI output must always be validated by humans.
