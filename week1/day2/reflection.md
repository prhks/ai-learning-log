# Reflection – Module 2

## What I Learned :
- Security and privacy risks when using AI coding tools
- Code ownership, licensing, with AI-generated code
- Risks of bias and over-reliance on AI outputs
- When NOT to use AI (security-sensitive code, PII, learning fundamentals)

## What Surprised Me
- How easily sensitive data can leak through prompts
- AI-generated code may have unclear ownership or licensing issues
- How confident but insecure AI output can look

## How I Will Use This
- Avoid AI for sensitive, security-critical, or learning-focused tasks
- Never include PII or secrets in prompts
- Treat AI output as a starting point, not final code
- Follow clear team level AI usage guidelines
