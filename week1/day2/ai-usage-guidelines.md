# AI Usage Guidelines

## Purpose
Define safe and responsible use of AI tools within the team.

## Allowed Uses
- Code suggestions and refactoring
- Documentation and comments
- Brainstorming solutions

## Prohibited Uses
- Sharing confidential or personal data
- Generating security-critical logic
- Replacing learning or assessments

## Data Handling Rules
- Never include secrets or PII in prompts
- Use sanitized or synthetic data only

## Accountability
Developers are responsible for reviewing and validating all AI-generated outputs.

## Review
AI-generated code must follow existing code review processes.
