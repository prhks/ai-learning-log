# Reflection – Module 5 (TDD with AI)

## What I Learned
- How to maintain TDD discipline while using AI tools
- ZOMBIES framework for systematic test case generation
- When AI strengthens vs weakens TDD practice
- Combining human judgment with AI for code reviews
- Test-first approach using AI to generate test scenarios
- Maintaining code quality throughout Red-Green-Refactor cycle

## What Surprised Me
- How AI can help discover edge cases I wouldn't think of
- The risk of AI undermining TDD if used carelessly
- How important it is to experience the "Red" phase
- That AI-generated tests need as much review as AI-generated code
- The effectiveness of multi-agent code review approach

## How I Will Use This
- Always generate tests BEFORE implementation when using AI
- Use ZOMBIES framework to structure test generation prompts
- Review and understand every AI-generated test
- Leverage AI for refactoring while keeping tests green
- Combine AI pre-review with human code review
- Use AI to speed up TDD without skipping the discipline

## Scenarios Where AI Helps TDD
1. **Edge case discovery** - AI suggests test scenarios I might miss
2. **Test boilerplate generation** - Speeds up the mechanical parts of test writing
3. **Refactoring support** - AI suggests improvements while tests provide safety net

## Scenarios Where AI Hinders TDD
1. **Generating implementation and tests together** - Skips Red-Green-Refactor cycle
2. **Over-reliance without understanding** - Prevents learning TDD patterns
3. **Accepting tests blindly** - Tests may not verify the right behavior

## Key Takeaways

### TDD Fundamentals
- Red-Green-Refactor cycle is non-negotiable
- Tests should be written first to guide design
- Small steps and frequent feedback are essential
- Refactoring is part of the process, not optional

### Using AI Effectively
- Generate test scenarios, not complete solutions
- Review AI output critically
- Maintain the test-first discipline
- Use AI to amplify skills, not replace them

### Code Quality
- AI can help maintain high standards
- Human judgment is essential for trade-offs
- Combine multiple perspectives (AI + human)
- Quality is a continuous practice, not a one-time check

- Explore multi-agent code review in team setting
- Build TDD templates and prompts for future use
