# Prompt Iterations (Progressive Improvement)

## Task
Explain Python lists to a beginner.


## Prompt 1 (Very Basic)
"Explain Python lists."

❌ Too vague


## Prompt 2
"Explain Python lists with examples."

✔ Adds examples


## Prompt 3
"Explain Python lists to a beginner with simple examples."

✔ Defines audience


## Prompt 4
"Explain Python lists to a beginner using simple language and 2 examples."

✔ Adds constraints


## Prompt 5
"You are a Python tutor. Explain Python lists to a beginner using simple language and 2 examples."

✔ Adds role


## Prompt 6
"Explain Python lists step by step to a beginner using simple language and 2 examples."

✔ Adds structure


## Prompt 7
"Explain Python lists step by step to a beginner, including common mistakes."

✔ Adds depth


## Prompt 8
"Teach Python lists to a beginner using a real-world analogy and 2 examples."

✔ Improves understanding


## Prompt 9
"Teach Python lists to a beginner using a real-world analogy, 2 examples, and a short practice question."

✔ Adds learning outcome


## Prompt 10 (Best)
"You are a Python instructor. Teach Python lists to a beginner using a real-world analogy, 2 simple examples, common mistakes, and a short practice question."

✅ Clear, structured, effective


## Key Learning
- Small prompt changes create big quality improvements
- Role, audience, structure, and constraints matter
