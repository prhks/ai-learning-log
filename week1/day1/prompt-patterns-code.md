# Prompt Patterns for Code Tasks


## Pattern 1: Role + Task + Constraints

**Template:**
"You are a [role]. Perform [task] with [constraints]."

**Example:**
"You are a senior backend engineer. Write a Python function to validate email addresses without using external libraries."

✔ Improves correctness and style


## Pattern 2: Step-by-Step Reasoning

**Template:**
"Think step by step before producing the final answer."

**Example:**
"Explain how to reverse a linked list. Think step by step."

✔ Reduces logical errors


## Pattern 3: Example-Driven Prompting

**Template:**
Input → Output examples, then new input

**Example:**
Input: "hello" → Output: "HELLO"  
Input: "world" → Output: "WORLD"  
Now convert: "ai"

✔ Excellent for transformations


## Key Takeaway
Prompt patterns make results more predictable and reusable.
