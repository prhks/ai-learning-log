# LLM Basics

## 1. What is an LLM?
- Definition: A Large Language Model (LLM) is a type of AI model trained on massive amounts of text to predict and generate human-like language.
- Examples: GPT-4, Claude, Gemini, LLaMA
- Key use cases: text generation, summarization, coding assistance

## 2. How LLMs Process Text
- Input text is tokenized into smaller units (tokens)
- Model predicts next tokens based on context
- Generates coherent outputs using probabilities

## 3. Tokens and Context Window (brief intro)
- Tokens: smallest unit of text the model sees (words or subwords)
- Context window: maximum number of tokens the model can “remember” at once
- Example: GPT-4 context window = 8,192 tokens (approx 6,000 words)

## 4. Key Concepts
- **Probabilistic generation**: Outputs are generated based on likelihood, not certainty.
- **Prompt engineering**: Designing effective input instructions to guide the model.
- **Zero-shot / Few-shot learning**: Performing tasks with no examples or a small number of examples in the prompt.
