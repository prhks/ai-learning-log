# AI Limitations


## 1. Hallucinations
LLMs can generate confident but incorrect information.

**Example:**
Inventing non-existent APIs or libraries.

**Why it happens:**
The model predicts likely text, not verified facts.

**Mitigation:**
- Ask for sources
- Verify critical outputs


## 2. Context Window Limits
LLMs forget earlier instructions in long conversations.

**Example:**
Forgetting formatting rules after many messages.

**Mitigation:**
- Restate important constraints
- Use summaries


## 3. No True Understanding
LLMs do not “understand” like humans.

**Example:**
Correct-looking but logically wrong explanations.

**Mitigation:**
- Test outputs
- Break tasks into steps


## Key Takeaway
LLMs are powerful tools, not decision-makers.
